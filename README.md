Palmera Heat is an original top-down open-world crime game set in sun-soaked Palmera City. Explore a coastal city on foot and by car, steal and drive distinct vehicles among live traffic and pedestrians, run a four-mission story chain for fixer Marisol Vega plus repeatable taxi and courier jobs, raise a 0–5 star wanted level with police pursuit, fight with fists and a pistol, clear the heat at repaint garages, and chase ten hidden palms. It features a full HUD with minimap, title / pause / busted / wasted / victory screens, synthesized WebAudio sound and music, and automatic saving in the browser. Vanilla JavaScript and canvas, no libraries, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or run the dossier build:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
